## Sobre

Este repositório reúne os projetos que desenvolvi no primeiro semestre de Engenharia de Software. A página inicial apresenta quem eu sou, minhas habilidades, minha formação e os projetos, cada um com prévia, descrição, tecnologias e link para abrir.

**Objetivo:** desenvolver projetos cada vez mais completos e crescer profissionalmente na área de Tecnologia da Informação.

## Habilidades

- **Desenvolvimento web:** HTML5, CSS3, JavaScript, Bootstrap 5 e design responsivo.
- **Linguagens:** JavaScript e Linguagem C.
- **Ferramentas:** Git, GitHub, GitHub Pages e VS Code.
- **Fundamentos:** lógica de programação, modelagem de banco de dados, acessibilidade e organização de código.

## O que pratiquei

- Estrutura semântica em HTML e acessibilidade (`aria-label`, textos alternativos e navegação por teclado).
- Layout responsivo com Flexbox, Grid e Bootstrap.
- Manipulação do DOM, validação de formulários e persistência com `localStorage`.
- Cálculos, filtros e visualização de dados com JavaScript.
- Levantamento de requisitos e modelagem de banco de dados.
- Versionamento com Git e publicação com GitHub Pages.
